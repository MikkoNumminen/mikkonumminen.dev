Aloitin syyskuun 2026 alussa full-stack-kehittäjänä Takaovi Palvelut Oy:ssä. Yritys toimii nimellä Asuntokanava. Se on noin 30 hengen PropTech-yritys Tampereella.

Työssä on kaksi osaa. Suurin osa on kiinteistönhallinnan legacy-alustan kehitystä. Loput on yrityksen IT-hallintoa.

## Rooli

Alusta on kirjoitettu C#:lla .NETin päälle ja pyörii Azuressa. Hallintakäyttöliittymä on tehty Angularilla. Erillinen asiakasportaali on rakennettu Laravelilla, Reactilla ja PostgreSQL:llä. Teen töitä molempien kanssa, backendistä frontendiin ja tuotantoon asti.

IT-puolella hallinnoin Microsoft 365:tä ja Entra ID -tenanttia ja toimin henkilöstön sisäisenä helpdeskinä.

## Mitä teen

Kehitys:

- C#- ja .NET-legacy-alusta Azuressa: App Services, Table Storage, Blob Storage, Key Vault, Azure AD B2C ja Application Insights.
- Angular-hallintakäyttöliittymä sekä Laravel-, React- ja PostgreSQL-asiakasportaali.
- M-Files-integraatio.
- Pankkiyhteysintegraatiot: maksuaineistot, tilitiedotteet ja pankkivarmenteet.
- Käyttäjien luonti, deaktivointi, poisto ja käyttöoikeuksien hallinta.
- Tuotantojulkaisut, release-prosessi ja smoke-testaus.
- Azure DevOps: pipelinet, pull request -käytäntö, code review ja release-hyväksynnät.
- Entra-sovellusten salaisuuksien ja varmenteiden inventaario.
- Azure-tallennuksen varmuuskopioauditointi ja varmuuskopioinnin suunnittelu.
- Tekninen dokumentaatio: havainnot, runbookit ja release-kirjaukset.
- AI-avusteinen työnkulku Claude Codella ja Codex CLI:llä, adversariaaliset review-kierrokset mukaan lukien.

IT-hallinto:

- Entra ID -tenantin hallinta erillisellä admin-tunnuksella.
- Azure RBAC:n siivous ja subscriptionien hallinta.
- Henkilöstön sisäinen IT-helpdesk.
- Yrityksen WordPress-sivusto, mukaan lukien Avada-teema ja lomakkeet, sekä yrityksen domainin DNS.
- Yhteydenpito web-toimiston, domain-rekisteröijän ja entisen IT-kumppanin kanssa.
