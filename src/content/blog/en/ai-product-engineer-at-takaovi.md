In August 2026 I started as an AI Product Engineer at Takaovi Palvelut Oy. The company operates as Asuntokanava. It is a PropTech company of about 30 people in Tampere.

The role has two parts. Most of it is development on a legacy property management platform. The rest is IT administration for the company.

## The role

The platform is written in C# on .NET and runs on Azure. It has an Angular admin frontend. A separate customer portal is built with Laravel, React and PostgreSQL. I work across both, from the backend to the frontend and into production.

On the IT side I administer Microsoft 365 and the Entra ID tenant, and I am the internal helpdesk for staff.

## What I work on

Development:

- The legacy C# and .NET platform on Azure: App Services, Table Storage, Blob Storage, Key Vault, Azure AD B2C and Application Insights.
- The Angular admin frontend and the Laravel, React and PostgreSQL customer portal.
- The M-Files integration.
- Bank connection integrations: payment files, account statements and bank certificates.
- User provisioning, deactivation, deletion and rights management.
- Production releases, the release process and smoke testing.
- Azure DevOps: pipelines, the pull request flow, code review and release approvals.
- An inventory of Entra app secrets and certificates.
- A backup audit and backup planning for Azure storage.
- Technical documentation: findings, runbooks and release records.
- An AI-assisted workflow with Claude Code and Codex CLI, including adversarial review rounds.

IT administration:

- Microsoft 365: user onboarding and offboarding, mailbox delegation, distribution groups, archives and aliases.
- Entra ID tenant administration, from a separate admin account.
- Azure RBAC cleanup and subscription administration.
- The internal IT helpdesk for staff.
- The company WordPress site, including the Avada theme and forms, and DNS for the company domain.
- Coordination with the web agency, the domain registrar and the former IT partner.
