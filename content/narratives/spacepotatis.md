## Origin

Spacepotatis is a live browser game: a potato in a shield bubble shooting bugs across a procedural galaxy, built as a Tyrian 2000-inspired vertical-scrolling shooter. The boot sequence imitates a vintage terminal, opens into a draggable 3D solar system, then drops into top-down combat. The first commit landed 2026-04-24, and the dated history shows the whole stack (shared types, the Kysely DB client, the Three.js overworld, Phaser entities and scenes, the GameState singleton, audio, NextAuth, and the API routes) scaffolded in a single burst on 2026-04-26. The project doc reports it went from empty repo to live game in 12 days.

## Key technical choices and the why

Three rendering systems coexist: Next.js 16 + React 19 wraps a Phaser 4 combat scene, while Three.js 0.184 + GSAP drive the galaxy overworld and the fade transition between them. PostgreSQL on Neon is reached through Kysely rather than an ORM: ADR 0002 records Prisma's rejection on three grounds: its generated engine binary does not run in Vercel's Edge runtime, it bloats the bundle and cold-start, and it fights hand-written migrations. The entire rendering posture is shaped by the Vercel Hobby quota (ADR 0001): most pages are `force-static`, and only the leaderboard is `force-dynamic`. Balance values live in `src/game/data/*.json` with Zod validation moved to CI-only tests, a measured ~98 KB cut from first-load JS (ADR 0005). Auth is Google OAuth only and optional. The single-player game works without signing in.

## Dead ends and how they resolved

The most consequential incident was the 2026-05-02 save wipe. Three server-side cheat guards checked that fields did not grow too fast; none checked for shrinkage, so a buggy client posting `credits=0` and `completedMissions=[]` overwrote real progression. The immediate fix landed across a cluster of PRs the next day (2026-05-03): a `validateNoRegression` guard, reclassifying 422 rejections as transient retries instead of permanent drops, a client-side hydration gate, the forensic `save_audit` table, cross-account email stamping on the save queue, and a `LoadResult` discriminated union replacing a lossy boolean that had collapsed "fresh account" and "server unreachable" into one. The structural fix (an append-only `save_snapshots` table dual-written on every save) landed 2026-05-18.

Earlier came the "MENI PERUNAPROGRESS HUKKAAN" bug (2026-04-26): signing in reloads the page via the OAuth redirect, resetting the in-memory GameState, and the save queue's required email stamp meant anonymous progress could not persist, so signing in silently wiped earned credits. The fix was an orthogonal `guestCache.ts` channel that writes synchronously on every commit while the player is anonymous. The WebGL context budget produced another: `forceContextLoss()` is needed to free GPU contexts during rapid galaxy/combat cycling, but it makes a canvas permanently unrecoverable, which broke warp (warp reuses the same mounted canvas). The resolution keys the galaxy canvas on `currentSolarSystemId` so React mounts a fresh element per warp. Late May, a run of commits chased a white-frame compositor flash on navigation, fixed by hiding the canvas synchronously before `router.push`. Dependency edges show their own dead ends: eslint 10 was reverted to ^9 as incompatible with the plugin chain, while Phaser was carried from 3.90 to 4.1.

## Notable implementation details

Every sprite is generated programmatically in `BootScene.generateTextures` via Phaser Graphics, no PNGs are preloaded. Mute lives in a single `AudioBus` fanning out to nine self-registering engines, and is deliberately session-only after persisted mute state once stranded pages silent on cold load (PR #70). All voice is generated by AudiobookMaker (Chatterbox engine) and music written in Strudel, with one "Grandma" narrator persona across every surface. The credits cheat-guard cap is derived per-request from the server's stored `completedMissions`, so a rebalance scales the cap with no code edit. A 2026-05-04 audit established a ten-module acyclic dependency graph (ADR 0007). The repo also ships thirteen version-controlled Claude Code skills as production artifacts.

## Outcome

Live at spacepotatis.vercel.app. The architecture doc cites approximately 1,170 Vitest tests on every CI push, with security regression tests as a dedicated CI step and a documented GDPR right-to-erasure runbook. The history through late May into early June shows sustained hardening: a batch of security SEC-* fixes, a save-architecture v2, and god-file refactors split into barrel modules.
