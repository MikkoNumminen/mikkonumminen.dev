# Strudel Patterns

**Algorithmic music in Strudel**

Strudel Patterns is a collection of live-coded electronic music written in Strudel: a JavaScript pattern engine and port of TidalCycles. Every track is a single composable expression: stacked synths, basslines, drum patterns, and effect chains layered in code rather than in a DAW.

The composition workflow is AI-directed: natural-language direction feeds into generation, then listen, then iterate, with decisions logged alongside the git history so every revision is traceable. The repo includes a reusable component library, curated synth presets, and session notes per iteration.

Selected tracks score Spacepotatis (galaxy overworld, mission themes, and the story narration bed) and the mikkonumminen.dev landing page. Every note in those soundtracks traces back to this repo.

## Highlights

- Live-coded in Strudel (JavaScript pattern engine, port of TidalCycles)
- AI-directed iteration with decisions logged in git
