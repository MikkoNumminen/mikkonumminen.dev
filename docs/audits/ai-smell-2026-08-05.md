   so the red-team suite drives the real gate, or point the suite at the

   passes, or better, consolidate the retrieve-and-score block into one shared
   assembly. That same consolidation resolves `eval_arm.py:59`.
3. `src/i18n/locales/fi.ts:140-141`: rewrite the Finnish portfolio card against
   `en.ts:136` and add the missing `highlights`.

The mediums cluster into comment-drift deletions (ratelimit, Shoutbox), locale
gaps (Terminal aria-label), weak assertions (tuning.test), and rule-of-three
extractions (llm.py, eval_arm). The lows are individually trivial; batch them
by family, not by file.

## What this audit is not

It is pattern-matching against a fixed smell list on one commit. Most lows are
working code whose docs, guards or attributes mislead a reader rather than
break a visitor; severity here ranks how wrong the repo's own claims are, not
runtime damage. The robustness findings live in
[audit-2026-08-05.md](./audit-2026-08-05.md); the prompt-boundary findings in
[llm-injection-2026-08-05.md](./llm-injection-2026-08-05.md). Overlap between
the three reports is deliberate where the same line carries both a smell and a
defect.
